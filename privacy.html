PRIVACY POLICY

Keter Files · last updated October 7, 2026

Keter Files ("the tool") is a private production tool operated by the owner of the Keter Files YouTube channel for that channel only. The tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and the Google Privacy Policy applies to data handled by Google.

What data the tool accesses

With the channel owner's OAuth consent (scope youtube), the tool reads the name of the authorised channel and uploads videos, titles, descriptions and tags that the owner has approved. It does not read comments, subscribers, watch history or any data of other users, and it has no other users.

What is stored, and where

The OAuth refresh token and the channel name are stored only on the owner's own computer, in a file readable only by the tool. The IDs and links of uploaded videos are kept in the tool's local database. Nothing is sold, shared with third parties or used for advertising.

Retention and deletion

Stored YouTube data is kept only while the tool is connected. Disconnecting in the tool deletes the token immediately; any other data obtained from YouTube API Services is refreshed or deleted within 30 days.

Revoking access

Access can be revoked at any time on the Google security settings page: security.google.com/settings/security/permissions.
