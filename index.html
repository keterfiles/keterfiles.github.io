KETER FILES

Keter Files is a YouTube channel of short animated videos adapting articles from the SCP Foundation wiki. Every video is an original 2D animation made in code, narrated with synthetic voices, and credits the original authors under CC BY-SA 3.0 in its description.

Channel: youtube.com/@keterfiles

The production tool

The channel is produced with a private tool that runs on the creator's own computer. After the creator watches and approves a finished video, the tool uploads it to the creator's own channel through the YouTube Data API (YouTube API Services). The tool has one user — the channel's owner — and is not offered to anyone else.
